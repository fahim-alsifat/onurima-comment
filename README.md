# অরুমিনা পুস্পপথ (Arumina Pushpapath)

A beautiful, interactive pinboard-style website with a floral theme. This web application allows users to create, edit, and organize colorful posts (like sticky notes) and add comments to them.

## Features

### Post Management
- Create, edit, and delete posts styled as colorful sticky notes
- Drag and drop functionality to rearrange posts on the pinboard
- Search posts by title or content
- Color customization for posts
- Clear all posts with confirmation

### Comments System
- Add comments to selected posts
- Each line break creates a separate comment
- Copy comments to clipboard with a single click
- Search comments
- Clear all comments with confirmation

### Data Persistence
- All posts and comments are saved to the browser's local storage
- Data is automatically loaded when revisiting the page

### Visual Design
- Floral-themed aesthetic with soft pastel colors
- Responsive design that works on various screen sizes
- Smooth animations and transitions for a delightful user experience

## Technologies Used
- HTML5
- CSS3 (with custom SVG patterns)
- JavaScript (Vanilla JS)
- Local Storage API for data persistence
- Drag and Drop API

## Getting Started
1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start adding posts and comments!

## Usage

### Adding a Post
1. Click the "Add Post" button
2. Enter a title and content
3. Choose a color or use the randomly assigned one
4. Click "Save"

### Editing a Post
1. Click the edit (pencil) icon on any post
2. Modify the title, content, or color
3. Click "Save"

### Adding Comments
1. Select a post by clicking on it
2. Type your comments in the comment area (each line will become a separate comment)
3. Click "Add Comments"

### Managing Posts and Comments
- Use the search bars to filter posts or comments
- Use the "Clear All" buttons to remove all posts or comments (with confirmation)
- Drag posts to rearrange them on the pinboard
